# AI-NPC-Forgemind-
仓库介绍（README 首屏用） AI-NPC-Forgemind — 本地、私有、可无限自定义的多身份 AI 游戏 NPC 记忆系统。  通过四子 Agent 流水线（A1 记忆搜索 → A2 深度思考 → A3 最终输出 → A4 记忆管理）和为每个 NPC 独立隔离的分层记忆（核心 / 场景 / 工作）+ 游戏设定数据库，让 NPC 记住你、遵守世界设定、不凭空编造。  亮点：  🧠 分层长时记忆：自动摘要、事件切分、升降级与衰减，跨会话不失忆 📚 每身份独立游戏库：按"食物 / 道具 / 怪物 / 地形 / 地点 / 世界观"分类，手写 JSON 即可接入，告别版权枷锁 ⚙️ 自定义角色零门槛：既有自动录入（30 句对话样本提炼画像），也可手动建库 （本人首个练手AI项目）
